# Demo Sounds

Sounds of the key presses and mouse clicks heard in the demo videos. All of them are in the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), trimmed to their audible part and converted to mono Ogg Vorbis.

| Files                                  | Source                                                                                                                                                          | Author                                       |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `key-1.ogg` … `key-6.ogg`              | Single keypresses 002, 003, 011, 014, 025 and 031 of [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes) | unicaegames                                  |
| `mouse-press.ogg`, `mouse-release.ogg` | `mouseclick1` and `mouserelease1` of [UI SFX Set](https://opengameart.org/content/51-ui-sound-effects-buttons-switches-and-clicks)                              | Kenney ([kenney.nl](https://www.kenney.nl/)) |
